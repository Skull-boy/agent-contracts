## Publish and attestation triggers (read-only)

`publish-pypi.yml`:

- Trigger: `on: push: tags: ['v*']` (lines 3–6).
- Gate: package version must equal the tag version (lines 41–50).
- Builds wheel/sdist, uploads `dist` for attestation, installs the built wheel
  from `site-packages`, verifies the CLI/API, runs the suite, then publishes
  via PyPI Trusted Publishing (lines 52–104).

`release-attest.yml`:

- Triggers: `workflow_run` for `["Publish to PyPI"]` with `types: [completed]`
  and `workflow_dispatch` (lines 18–22).
- Gate: the `attest` job runs only when the completed publish run concluded
  `success` (lines 32–34).
- It downloads that run's `dist` artifact, installs the exact wheel, runs
  `scyvera self-check` against the shipped manifest (lines 75–78), regenerates
  the manifest from the installed tree and self-checks again (lines 91–92),
  emits the SBOM/release manifest, attests provenance (lines 109–115), and
  uploads the assets to the tag's GitHub Release (lines 117–136).
